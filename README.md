# integrations

Standalone integration packages (source `.kspkg` workers) split from
`cortex/packages`. Each package carries its own `manifest.json` and version
and is released independently through Package Index.

Packages: bigfrontend, codewars, greatfrontend, hevy, huawei-health,
leetcode, toggl, raycast-api, ark-markdown-bridge.
